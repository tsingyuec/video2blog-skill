- 产物：
  - [`blog.md`](blog.md) — 最终博客（金字塔写作 + 术语速查表 + 可点击时间戳回链）
  - [`transcript.md`](transcript.md) — 第 4 步的「图-字幕」原始文稿（左字幕、右代表帧）

> 配图（博客 20 张 + 文稿 260 张，共约 23M）托管在**同仓库的 [`media` 分支](https://github.com/tsingyuec/video2blog-skill/tree/media)**，正文引用其 `raw.githubusercontent.com` 直链。这样做是因为 `npx skills add` 采用 `--depth 1` 浅克隆，只拉默认分支——把大图放到 `media` 分支既不撑大安装体积，又不影响本页渲染。
